🗺️ Carte des centres d'aide

Au démarrage, les grandes villes et repères nationaux sont déjà visibles. Toutes les communes de France (y compris les petites villes et villages) sont cherchables : tapez le nom ou le code postal dans la barre en haut, ou zoomez sur la carte — les centres réels (OpenStreetMap) se chargent alors automatiquement. Cliquez sur un marqueur pour les détails et l'itinéraire.

💡 Astuce : seuls les grands centres sont affichés au début pour alléger la carte. Pour une petite ville ou un village, utilisez la recherche en haut de page — les structures locales apparaîtront ensuite.

⚠️ Les lieux « Repère » ont une position approximative (centre-ville) : ils signalent le type de structure présent dans la ville et renvoient vers le site officiel. Les autres viennent d'OpenStreetMap (données collaboratives, parfois incomplètes ou dépassées). Appelez ou vérifiez avant de vous déplacer.
